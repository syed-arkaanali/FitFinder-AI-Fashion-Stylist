## ✨ Features

### 📊 Machine Learning Predictions

FitFinder uses Machine Learning models to:

- Predict the user's **Body Type**
- Recommend a **Clothing Size**
- Through user's height, weight, waist circumference, arm length, upper leg length, and age.

### 👤 Personalized Recommendations

Users provide information such as gender and body measurements, allowing the AI Stylist to provide more personalized fashion recommendations.

### AI Fashion Stylist

FitFinder includes an interactive AI chatbot that can:

- Recommend outfits
- Suggest casual fashion ideas
- Suggest formal outfits
- Recommend seasonal styles
- Suggest color combinations
- Answer follow-up fashion questions

The chatbot uses the user's FitFinder prediction results as context to provide more personalized fashion guidance.

### 🎨 Fashion-Inspired Interface

The application features a custom **Red and Beige fashion-inspired design** built using Streamlit and CSS.

## 📋 Input Features

| Feature | Description |
|---|---|
| Gender | Used for personalized fashion recommendations |
| Height | User's height in centimeters |
| Weight | User's weight in pounds |
| Waist Circumference | Waist measurement in centimeters |
| Arm Length | Arm measurement in centimeters |
| Upper Leg Length | Upper leg measurement in centimeters |
| Age | User's age |

## ⚠️ Disclaimer

FitFinder provides **Machine Learning-based predictions** and **AI-generated fashion recommendations**.

- Clothing sizes can vary between brands.
- Predictions depend on the available training data.
- Users should check brand-specific size charts before purchasing clothing.
- Fashion recommendations are intended as personalized guidance.
